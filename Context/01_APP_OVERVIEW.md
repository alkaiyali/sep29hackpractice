# 01 — Meddy App Overview

## 1. Product Summary
**Meddy** is a modern, intuitive, and empathetic mobile health companion built with React Native and Expo SDK 54. It is designed to take the friction and anxiety out of medication adherence for individuals and family caregivers.

Whether managing personal prescriptions, daily vitamins, or coordinating the treatment regimen of aging parents, children, or loved ones, Meddy ensures medicines are taken at the right time, in the right dose, with complete accountability through a shared **Care Circle**.

---

## 2. Core Value Propositions
- **Zero Missed Doses**: Reliable scheduled local reminders with configurable alarm sounds, haptic vibrations, and customizable snooze intervals.
- **Visual Confidence**: Capture photos of pill bottles, blister packs, or medicine shapes directly via Camera or Gallery to prevent medication mix-ups.
- **Collaborative Care Circle**: Connect caregivers and family members seamlessly using QR code generation and instant camera scanning. Track medication compliance for loved ones remotely or collaboratively.
- **Calm, Frictionless UX**: Clean, medical-grade interface built for all age groups, eliminating clutter and cognitive overload.

## 3. Four Core Sections

```

│                            MEDDY                            │
├───────────────┬───────────────────┬──────────────┬──────────┤
│ 1. Dashboard  │ 2. Medicines      │ 3. Care      │ 4.Profile│

├───────────────┼───────────────────┼──────────────┼──────────┤
│ • Daily View  │ • Medicine Catalog│ • QR Connect │ • Account│
│ • Due Alarms  │ • Add / Edit Form │ • Member Roster • Settings│
│ • Circle Quick│ • Custom Alarms   │ • Circle Meds│ • Health │
│   Summary     │ • Photo & Dosage  │ • Shared Logs│   Info   │
└───────────────┴───────────────────┴──────────────┴──────────┘
```

1. **Dashboard**: Daily command center showing upcoming/due medicines for today, quick "Take" or "Snooze" actions, streak/adherence health indicators, and a high-level overview of the active Care Circle.
2. **Medicine Section**: Comprehensive medication management. Add and view medicines with deep clinical and practical details (Name, Dosage, Units, Medicine Form, Instructions, Notes, Photos, and customized Alarm Schedules).
3. **Care Circle**: Family/caregiver coordination hub. Create a new circle or join an existing circle via QR code. Assign and monitor medicine reminders for loved ones.
4. **Profile**: Personal health profile, emergency contacts, notification permissions, theme settings, and data backup/reset options.
